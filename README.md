# 1917: whirlwind of revolution

an interactive telegram bot based on the events of the russian revolution of 1917.

users choose a historical character and make decisions on their behalf, following a branching storyline that leads to different possible outcomes. after completing a scenario, the bot provides an alternative ending and the character's real historical outcome.

the project was created for a competition and **won 2nd place**

## characters

alexander kerensky

leon trotsky

vladimir lenin

lavr kornilov

alexandra kollontai

julius martov

pavel milyukov

vladimir antonov-ovseenko

maria spiridonova

## features

historical character selection

interactive branching storylines

multiple decision points

different endings based on user choices

historical outcome after completing a scenario

telegram reply keyboards for making decisions

individual user state tracking
